\section{Reproducibility and Artifact Availability}
\label{sec:reproducibility}

In accordance with rigorous open-science standards, all software, smart contracts, benchmark harnesses, and raw evaluation datasets are publicly available:
\begin{itemize}
    \item \textbf{Repository}: \url{https://github.com/samudragupto/research-blob-da}
    \item \textbf{Git Working Branch}: \texttt{research/journal-extension}
    \item \textbf{Historical Release Baseline}: Tag \texttt{v0.1.0} (\texttt{0b523e7...}, commit \texttt{428c789...})
    \item \textbf{Environment Manifest}: Machine-readable environment capture in \path{benchmarks/journal-extension/manifests/environment.json}.
    \item \textbf{Raw Benchmark Datasets}: Raw trial-level records preserved under \path{benchmarks/journal-extension/local/}, \path{retrieval/}, \path{archival/}, and \path{security/}.
\end{itemize}

\subsection{Reproduction Commands}
The entire experimental evaluation and verification pipeline can be reproduced offline using standard command-line tools:
\begin{verbatim}
# 1. Smart Contract Tests (36 tests)
forge test

# 2. Python Test Suite (64 tests)
pytest

# 3. Benchmark Execution Pipeline
python python/capture_environment.py
python python/prepare_journal_datasets.py
python python/journal_experiments.py

# 4. Archival & Adversarial Evaluations
python python/archival_bridge.py
python python/adversarial_evaluation.py

# 5. Paper Artifact Generation
python python/generate_paper_artifacts.py
\end{verbatim}
All commands execute deterministically without requiring live network access or paid RPC credentials.
